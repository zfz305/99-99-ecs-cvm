## 300GB、不限流量和200M峰值，到底怎么算

300GB/月大约等于每天 10GB。普通企业站、博客、作品集，一个月通常跑不到这个数；图片站、软件下载、视频切片、公开图床，300GB 可能几天就见底。

腾讯云 99 元档给的是 4M 带宽。按峰值 512KB/s 一直跑满算，300GB 大约 7 天用完。真实网站不可能 24 小时满速，多数文字站的平均占用远低于峰值，所以 300GB 对普通站点够用。但如果你提供大文件下载，或者页面上挂了自动播放的视频，这个上限会很快变成账单。

超额部分按约 0.8 元/GB 计费。一个月多用 100GB，就是 80 元，已经接近一台 99 元服务器的价格。流量接近上限时，升级到 500GB 或 600GB 档，通常比事后付超额费划算。

阿里云 99 元 ECS 是 3M 固定带宽、不限流量。3M 峰值约 384KB/s，即使不限流量，24 小时满速跑一个月理论上限也只有约 970GB。它解决的是“流量不额外计费”的焦虑，不解决“我要 10M 以上稳定带宽”的需求。真要跑大带宽业务，还是得看 12M、14M 这些档位。

阿里云 38 元轻量的 200M 是峰值带宽，活动页明确说明实际可能达不到，不承诺持续跑满。它适合突发下载、临时活动页，不适合要求稳定带宽的视频会议后端。腾讯云的 4M 是固定带宽，速度上限低，但更可预期。

## 下单前重点确认五件事

1. **地域**：选离主要用户最近的城市。腾讯云 99 元档只有北京、上海、广州、成都；阿里云 99 元 ECS 城市更多。买之前先看你的用户在哪。
2. **月流量**：估算每月出站流量。文字站通常够用，下载站、视频站、图床直接看 500GB 以上档位，或者选不限流量的阿里云 ECS。
3. **带宽形态**：4M 固定带宽适合稳定访问，200M 峰值适合突发。别把“峰值 200M”理解成“持续 200M”。
4. **系统盘**：40GB 装完系统、宝塔、Docker 镜像后剩余不多。准备跑多个容器，直接选 50GB 或 60GB 档。
5. **续费条件**：99 元档写明续费同价，38 元秒杀要看活动规则。主力站别把长期成本押在秒杀价上。

## 常见问题：哪个快、流量够不够、续费会不会涨

### 阿里云和腾讯云服务器哪个速度快？

同地域、同配置下，两家速度差距很小。更影响访问速度的是服务器地域、带宽大小和你的用户位置。用户在广州，买广州节点；用户在成都，买成都节点。品牌本身不该是速度的第一变量。

### 腾讯云 99 元档的 300GB 流量够用吗？

普通文字站、企业展示站通常够用，平均每天 10GB。图片多、放视频、提供软件下载，就不够。超额约 0.8 元/GB，流量接近上限时升级套餐比付超额费划算。

### 阿里云的 200M 峰值带宽比腾讯云 4M 快吗？

理论峰值快很多，但 200M 是峰值，不承诺持续跑满；腾讯云 4M 是固定带宽，上限低但更稳定。做临时下载、活动页，阿里云 200M 有吸引力；做长期在线的业务，固定带宽更可预期。

### 已经有阿里云服务器，要不要换腾讯云？

现有机器跑得稳，不建议为了几十元差价迁移。两家之间不能直接快照迁移，重装环境、迁数据、改解析都要花时间。新项目可以开一台腾讯云机器，老项目继续跑。

### 99 元档续费真的不涨价吗？

公开活动页把 99 元档的续费价写成 99 元/年，但活动规则可能调整，续费时以页面显示为准。买之前把续费条件截图保存，比只看首年价格靠谱。
